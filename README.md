# Minesweeper (Python)

## Overview

This is a simple **Minesweeper game written in Python**.
The goal is to reveal all the cells without hitting a mine.

## Features

* Random mines placement
* Reveal cells
* Flag mines
* Win / Lose system

## How to Run

```bash
python main.py
```

## How to Play

* Choose a cell to reveal
* Avoid mines 
* Numbers show nearby mines
* Win by clearing all safe cells
